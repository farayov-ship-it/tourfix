# TourFix

Zamonaviy, tez ishlaydigan O'zbekiston transfer va gidlar sayti — TourFixer.uz ga o'xshash, lekin yangi dizayn bilan.

## Xususiyatlar

- **Three.js WebGL hero** — Ipak yo'li spirali particle animatsiyasi
- **3 til** — English, Русский, O'zbek
- **Transferlar** — 240+ marshrut, 21 avtomobil turi
- **Gidlar** — Samarqand, Buxoro, Xiva, Toshkent
- **Kunlik sayohatlar** — hammasi kiritilgan turlar
- **WhatsApp booking** — bir bosishda buyurtma
- **Tez yuklanish** — Next.js 15 SSG, lazy 3D, mobil optimizatsiya

## Ishga tushirish

```bash
npm install
npm run dev
```

Brauzerda oching: **http://127.0.0.1:3001/en**

(Port 3000 band bo‘lishi mumkin — loyiha 3001 portda ishlaydi)

## Production build

```bash
npm run build
npm start
```
